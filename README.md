# 🐶 Dog Explorer

A responsive web application that fetches and displays random dog images using the Dog CEO API.

## ✨ Features

- 🐶 Fetch random dog images
- 🔄 Get a new dog image with a button click
- 📱 Responsive design
- ⚡ Uses JavaScript async/await
- 🛡️ Handles API errors using try/catch

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🔗 API Used

Dog CEO API:  
https://dog.ceo/api/breeds/image/random
